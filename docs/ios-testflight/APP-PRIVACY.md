# App Privacy — déclaration préparée pour le client iOS actuel

À saisir dans **App Store Connect → Apps → NailMoods → App Privacy → Get Started / Edit**. Date de l'audit : 5 octobre 2026. Déclarer les données collectées dans au moins un parcours, même si ce parcours est facultatif. Les données restant exclusivement sur l'appareil ne constituent pas à elles seules une collecte serveur. Le tableau décrit les parcours cloud réellement présents ; la déclaration doit être relue avant toute ouverture d'une nouvelle technologie.

Toutes les données collectées ci-dessous sont **liées au compte** ou susceptibles de l'être. Aucun usage de tracking publicitaire inter-apps/sites n'a été trouvé. Répondre **No** à « used for tracking » pour ces catégories dans cette version. La mesure d'audience interne consentie ne justifie pas à elle seule ATT. Pas d'IDFA, SDK publicitaire, attribution ou vente de données dans le code audité.

La liste de choix Apple à activer d'après le tableau est : **Name, Email Address, User ID, Photos or Videos, Emails or Text Messages, Other User Content, Customer Support, Purchase History, Product Interaction, Other Diagnostic Data, Coarse Location, Other Data Types**. Sélectionner les finalités détaillées par catégorie, toutes liées, sans tracking. Ne cocher ni Third-Party Advertising ni Developer's Advertising or Marketing pour le comportement actuel.

Le manifest `ios/App/App/PrivacyInfo.xcprivacy` correspond à ces catégories. Il déclare UserDefaults **CA92.1** et File Timestamp **C617.1** : données/préférences propres à l'app et fichiers de son conteneur. Les manifests des plugins Capacitor sont embarqués lors du build ; ils ne remplacent pas la déclaration App Privacy faite dans Connect.

Les logs d'infrastructure (Supabase, fournisseur email), leur rétention et d'éventuels prestataires configurés hors dépôt doivent être confirmés par le responsable du service. L'audit n'a pas lu les secrets SMTP ni les logs personnels. Si une intégration externe collecte des identifiants ou diagnostics au-delà de ce tableau, compléter la déclaration avant de distribuer le build. Ne pas prétendre avoir audité une configuration invisible.

Politique de confidentialité et CGU : utiliser les liens HTTPS déjà fournis par `LegalLinks` dans l'app. Vérifier qu'ils s'ouvrent sans authentification et que les coordonnées du responsable, suppression et durées reflètent l'exploitation réelle. Renseigner la même Privacy Policy URL dans Connect.
