# NailMoods illustrated pictograms

Three original PNG boards supplied by the project owner on 2026-09-28. Files are byte-identical to the uploads:
- `nailmoods-styles.png`: 1000055870.png — styles, moods and aesthetics (46).
- `nailmoods-techniques.png`: 1000055871.png — techniques (53).
- `nailmoods-effects-themes.png`: 1000055872.png — finishes (22) and themes (28).

All 149 artwork regions are mapped in `src/iconAtlas.js`. `MoodGlyph` uses clipped SVG viewports over the original raster images. The black board background is keyed out at display time. Labels and headings from the boards are excluded; accessible French interface labels remain real text. These are raster assets, not vector originals.

Artwork colors are fixed and independent of product colors, user-selected nail colors and application theme. Lucide icons remain for navigation and generic actions.
